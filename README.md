# Local Knowledge OS

本地知识库：把你的 PDF、Word（.docx / .doc / .odt）、PowerPoint（.pptx / .odp）、表格（.xlsx / .csv / .ods）、Markdown 与 Obsidian 笔记、
文本、网页、RTF、电子书（EPUB）、Mac 备忘录在本机建成索引，用本机的 Qwen3 4B（或你配置的在线模型）回答问题，
每个回答都标出处（文件名 + 页码 / 幻灯片 / 标题 / 行号），点一下就能核对原文。默认完全离线；只有你选了在线模型时，才会把检索到的片段发出去（发送前可以确认）。

## 使用

**双击 `LKOS.app`**。第一次打开会自动安装窗口组件（约一分钟，需要联网），并会顺带打开 Ollama。

- **添加资料**：左栏资料库旁的“+”，或把文件夹拖进窗口。索引在后台进行，提问时自动让路；到了更新时间（默认每周）的文件夹，会在接通电源、你没在用电脑时自动更新。
- **四种方式**（输入框左下）：
  - **对话**：直接和模型聊，不查资料库（不用向量和关键词检索），回答来自模型本身的知识，没有出处。
  - **关键词检索**：按原文逐字查找（空格分开的词都要出现，引号括起来的按整体），按文件列出目录和每一处的位置，不用模型，最快。只输入一两个词时，分析模式也会自动改用它。
  - **分析**：理解问题后找资料，用文档写出带出处的回答。⌘↩ 发送（↩ 换行；中文输入法里用回车选词不会误发）。点回答里的 [1]、[2] 在右侧看原文。
  - **深度分析**：拆解问题、把关键词写成中英法三种分别检索全部资料，再按方面分析；有总进度条。默认用中文回答，对话一直用英文或法文时跟着用。
- **对话**：回答完直接接着问就是追问，整串对话连续显示；⌘N 开新对话。每个回答底部写明是哪个模型答的。点某一轮的“分支”，保留到这一轮为止的内容另开一个对话。
- **模型**（左栏“模型”）：
  - 在线模型：预置模型厂商（Claude、OpenAI、DeepSeek、通义千问、Kimi、智谱、Gemini、Mistral、xAI）和第三方聚合 / 推理服务（OpenRouter、Nous Research、Together、Groq、Fireworks、DeepInfra、硅基流动、火山引擎方舟），也可以填自定义接口（OpenAI 兼容或 Anthropic 格式，每项都有说明和示例）。密钥目前明文保存在 `data/models.json`（不进 Git）。
  - 本机模型：从 Ollama 已下载的模型里选，换了更大内存的电脑可以换更强的模型。
  - 向量模型：可以更换；换后会让你选要重新索引的文件夹，以及现在开始还是闲时进行。
  - 对话里每一轮都可以在输入框旁选本机或在线模型。检索总在本机进行；本机模型只带最近 3 轮对话，在线模型带上整个对话和之前各轮找到的资料。
- **发往在线模型的内容**：默认只发本轮检索到的资料片段和对话记录；发送前列出片段，可以去掉不想发的（模型页可关闭这一步）；第一次用某个在线模型要先确认；想让它读整份文件，点 📎 或输入 @ 附加（本机模型则改为只在附加的文件里检索）；文件夹设置里关掉“允许发送到在线模型”的，内容永远不发；每次发送都记在日志里。
- **限定范围**：输入框旁的“范围”可以只在某些文件夹、文件类型、标签或最近修改的文件里找；右侧出处卡片里点“只问这份文件”。
- **Mac 备忘录**：资料库页点“添加 Mac 备忘录”（命令行 `lkos notes add`）。第一次会请你允许 LKOS 访问“备忘录”（拒绝后可在“系统设置 → 隐私与安全性 → 自动化”里打开）。备忘录正文导出成 Markdown 存在 `data/apple-notes/`（不进 Git），之后每次更新索引时自动同步改动和删除；加锁的备忘录、共享的备忘录（含共享文件夹）、“最近删除”和附件不导出。出处里点“在备忘录中打开”直接跳到那一条。
- **Obsidian**：资料库页点“添加 Obsidian 仓库”，从 Obsidian 打开过的仓库里选（也可以像普通文件夹一样添加）。双链 `[[笔记|别名]]`、嵌入、==高亮==、提示块、属性都按文字解析，`%%注释%%` 和 dataview 查询不索引；属性里的 tags 和正文里的 #标签 自动成为文件标签；白板（.canvas）里的卡片、分组、连线文字也能检索。出处里点“打开”直接在 Obsidian 中打开那条笔记。
- **文件夹改名 / 移动**：在访达里给资料库的文件夹改名，或在附近挪动位置，LKOS 下次打开资料库或更新时自动认出来，索引、设置、标签都保留，不用重建；以前对话里的出处也照样能打开。认不出来时（如移到别的磁盘），文件夹显示“找不到文件夹”，点“重新定位”选它现在的位置即可（重新添加同一个文件夹也会自动认出）。文件夹里面的子文件夹、文件改名不用管，更新时按内容认出。
- **资料体检**：资料库页的“资料体检”按格式统计每个文件夹（也可以检查还没添加的文件夹）：哪些能索引、哪些要另存为（.ppt / .xls / WPS / Pages·Keynote·Numbers，附办法）、哪些不支持（图片、音视频、压缩包等），以及还没从 iCloud 下载到本机的文件、超过大小上限的文件、文件夹里的 Obsidian 仓库。只看文件名和大小，不读内容。命令行：`lkos survey <文件夹>`。
- **标签**：索引完成后，空闲时自动给每份文件生成几个主题标签（设置里可关）；出处卡片里可以手动加、删，资料库页点一个标签就只在这些文件里提问。
- **文件夹设置**：资料库里每个文件夹的“设置”：自动更新周期（每天 / 每周 / 每月 / 只手动）、排除子文件夹或文件（如“归档”“*草稿*”）、不索引某些类型、扫描版 PDF 文字识别（macOS 自带，离线）、是否允许发送到在线模型。改了排除规则或文字识别后不会自动重建，文件夹上会提示“现在更新 / 稍后”。“需要处理的文件”里的扫描件旁有“打开文字识别”按钮。
- **关掉窗口后继续索引**：设置里打开后会安装一个后台服务（登录后自动运行），关窗期间照样按周期更新；打开应用时自动让给应用。
- **快捷键**：⌘N 新对话，Esc 停止生成，⌘1–⌘9 切换出处。
- **日志**：左下角“设置”里打开**开发者模式**，左栏出现“日志”，可以实时看检索到的片段、分数、首字时间、token 数、错误，以及每次模型调用的耗时和内存。

不想开窗口时，也可以在终端里用命令行：`source/bin/lkos`（交互式问答，`/help` 查看命令）。

## 文件夹里有什么

| 位置 | 内容 | 进 Git |
| --- | --- | --- |
| `LKOS.app` | 双击打开的应用 | 是 |
| `README.md` | 本说明 | 是 |
| `source/` | 程序代码、测试、安装与测试脚本 | 是 |
| `data/` | **私人数据**：文档索引数据库、问答记录、配置、日志（`data/logs/`） | **否** |
| `.venv/` | Python 运行环境 | 否 |

私人数据只留在本机：`.gitignore` 排除了 `data/`、所有数据库文件和文档文件；提交前的检查还会拦下误加的私人文件。

## 安装（第一次）

需要 macOS（Apple Silicon）和 [Ollama](https://ollama.com)。在终端里进入这个文件夹，运行：

```bash
source/scripts/setup_mac.sh
```

它会下载模型（qwen3:4b-instruct、bge-m3）、创建 `.venv`、安装程序并跑一遍测试。
8 GB 内存的机器建议再运行一次 `source/scripts/ollama_tune.sh`（开启 Flash Attention 与 8 bit KV 缓存，重启电脑后需再运行）。

## 开发

```bash
source/scripts/test.sh          # 单元测试 + 功能测试 + 覆盖率（不需要 Ollama）
source/scripts/test.sh --live   # 加上真实模型测试
```

测试的临时文件在 `.pytest_tmp/`（不进 Git），可以随时删除。

命令行还有：`lkos source set`（文件夹设置）、`lkos tags list / auto`（标签）、`lkos daemon install / uninstall / status`（后台服务）。

**目前的限制**：加密文件、旧版 .ppt 会被跳过，资料库页会列出这些文件和处理办法（旧版 .doc 用 macOS 自带工具自动转换）；扫描件要在文件夹设置里打开“文字识别”才会被检索；本机模型的上下文只有 4K，长对话只带最近 3 轮；PDF 还不能直接跳到引用的那一页；在线模型的密钥目前明文保存在 data/models.json。

**评测**：双击 `source/scripts/run_eval.command`，用 `data/eval/` 里的题目评测当前版本并和上次对比（约 15–20 分钟）。
