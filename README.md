# Local Knowledge OS

本地离线知识库：把你的 PDF、Word（.docx / .doc）、PowerPoint（.pptx）、Markdown 建成索引，用本机的 Qwen3 4B 回答问题，
每个回答都标出处（文件名 + 页码 / 幻灯片 / 标题 / 行号），点一下就能核对原文。文档内容不会离开这台电脑。

## 使用

**双击 `LKOS.app`**。第一次打开会自动安装窗口组件（约一分钟，需要联网），并会顺带打开 Ollama。

- **添加资料**：左栏资料库旁的“+”，或把文件夹拖进窗口。索引在后台进行，提问时自动让路；到了更新时间（默认每周）的文件夹，会在接通电源、你没在用电脑时自动更新。
- **提问**：输入问题，**⌘↩ 发送**（↩ 换行；中文输入法里用回车选词不会误发）。先在右侧列出找到的资料，再逐字出回答；点回答里的 [1]、[2] 查看原文，“打开原文件”直接打开。回答下方点 **追问** 可以接着上一轮问。
- **四种模式**（输入框左下）：
  - **问答**：默认。
  - **搜索**：只找原文、不生成回答，很快。只输入一两个关键词（如“AI”）时也会自动改为搜索。
  - **提取**：把资料里的信息整理成表格，每行带出处，可 **导出 CSV**。例如“列出各项目的名称、预算和负责人”，或写明“字段：客户、金额、日期”。
  - **深度分析**：先把问题拆成几个方面分别查资料，再按方面分析、给出结论（约 1–2 分钟）。
- **限定范围**：输入框旁的“范围”可以只在某些文件夹、文件类型、标签或最近修改的文件里找；右侧出处卡片里的“只问这份文件”“从这份文件提取”“总结这份文件”针对单个文件。
- **标签**：索引完成后，空闲时自动给每份文件生成几个主题标签（设置里可关）；出处卡片里可以手动加、删，资料库页点一个标签就只在这些文件里提问。
- **文件夹设置**：资料库里每个文件夹的“设置”：自动更新周期（每天 / 每周 / 每月 / 只手动）、排除子文件夹或文件（如“归档”“*草稿*”）、不索引某些类型、扫描版 PDF 文字识别（macOS 自带，离线）。
- **关掉窗口后继续索引**：设置里打开后会安装一个后台服务（登录后自动运行），关窗期间照样按周期更新；打开应用时自动让给应用。
- **快捷键**：⌘N 新问题，Esc 停止生成，⌘1–⌘9 切换出处。
- **日志**：左下角“设置”里打开**开发者模式**，左栏出现“日志”，可以实时看检索到的片段、分数、首字时间、token 数、错误，以及每次模型调用的耗时和内存。

不想开窗口时，也可以在终端里用命令行：`source/bin/lkos`（交互式问答，`/help` 查看命令）。

## 文件夹里有什么

| 位置 | 内容 | 进 Git |
| --- | --- | --- |
| `LKOS.app` | 双击打开的应用 | 是 |
| `README.md` | 本说明 | 是 |
| `design/` | 设计文档、实测报告、项目摘要（索引见 `design/README.md`） | 是 |
| `source/` | 程序代码、测试、安装与测试脚本 | 是 |
| `data/` | **私人数据**：文档索引数据库、问答记录、配置、日志（`data/logs/`） | **否** |
| `.venv/` | Python 运行环境 | 否 |

私人数据只留在本机：`.gitignore` 排除了 `data/`、所有数据库文件和文档文件；提交前的检查还会拦下误加的私人文件。

## 安装（第一次）

需要 macOS（Apple Silicon）和 [Ollama](https://ollama.com)。在终端里进入这个文件夹，运行：

```bash
source/scripts/setup_mac.sh
```

它会下载模型（qwen3:4b-instruct、bge-m3）、创建 `.venv`、安装程序并跑一遍测试。
8 GB 内存的机器建议再运行一次 `source/scripts/ollama_tune.sh`（开启 Flash Attention 与 8 bit KV 缓存，重启电脑后需再运行）。

## 开发

```bash
source/scripts/test.sh          # 单元测试 + 功能测试 + 覆盖率（不需要 Ollama）
source/scripts/test.sh --live   # 加上真实模型测试
```

测试的临时文件在 `.pytest_tmp/`（不进 Git），可以随时删除。配置项与实现取舍见 `design/implementation-notes.md`。

命令行还有：`lkos source set`（文件夹设置）、`lkos tags list / auto`（标签）、`lkos daemon install / uninstall / status`（后台服务）。

**目前的限制**：加密文件、旧版 .ppt 会被跳过，资料库页会列出这些文件和处理办法（旧版 .doc 用 macOS 自带工具自动转换）；扫描件要在文件夹设置里打开“文字识别”才会被检索；追问只带上一轮问答；PDF 还不能直接跳到引用的那一页；远端模型只保留接口、默认关闭。

**评测**：双击 `source/scripts/run_eval.command`，用 `data/eval/` 里的题目评测当前版本并和上次对比（约 15–20 分钟）。
